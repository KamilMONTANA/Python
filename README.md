## 🛠️ Getting Started & Running the Projects

1. **Verify you have Python installed (v3.10+ recommended):**
   ```bash
   python --version
   ```

2. **Clone the repository locally:**
   ```bash
   git clone https://github.com/KamilMONTANA/Python.git
   cd Python
   ```

3. **Navigate to the desired project folder and run it:**
   ```bash
   cd "17 Day OOP Quiz game"
   python lesson1.py
   ```
