# 🧮 Day 10: Calculator

A console calculator utility supporting basic arithmetic operations. The program runs in an active session loop, allowing users to perform sequential operations without restarting the execution.

## 🎯 Project Goal
To practice custom function design, passing parameters, returning values using `return`, and controlling program loops based on user input.

## ✨ Features
- **Core Arithmetic:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Interactive Routing:** Users select operations via simple numeric indicators (1-4).
- **Persistent Sessions:** Prompts users at the end of each round to decide whether to run another calculation or exit.

## 📂 Project Structure
- `main.py` – contains the complete execution loop, arithmetic math operations, and output printing.

## 🎓 Key Learnings
- Constructing conditional blocks (`if`, `elif`, `else`) to process arithmetic actions.
- Implementing division validations to handle zero inputs safely.
- Designing readable terminal prompt flows.
- Controlling runtime flows with `while True` statement flags combined with selective `break` operations.

## 🚀 How to Run the Project
Make sure you have Python installed. Then run the following in your terminal:
```bash
python main.py
```
