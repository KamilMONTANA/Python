# 🎸 Day 2: Band Name Generator

A simple console application built in Python that generates a creative band name based on user responses (their hometown and pet name).

## 🎯 Project Goal
This project focuses on practicing basic input/output operations, string manipulation, and variable concatenation in Python.

## ✨ Features
- **Interactive Console:** Prompts the user for inputs using the `input()` function.
- **Dynamic Name Generation:** Concatenates user responses to create a tailored band name proposal.

## 📂 Project Structure
- `main.py` – the main program script containing all the application logic.

## 🎓 Key Learnings
- Using the `print()` function to output text to the console.
- Gathering user input dynamically using the `input()` function.
- Declaring and assigning values to variables.
- Concatenating strings using the `+` operator.

## 🚀 How to Run the Project
Make sure you have Python installed. Then run the following in your terminal:
```bash
python main.py
```
