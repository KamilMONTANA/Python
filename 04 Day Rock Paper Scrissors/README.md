# 🪨 Day 4: Rock Paper Scissors & Utilities

A collection of three mini console utilities in Python that showcase lists, basic math, and pseudorandom number generators. The centerpiece is a classic "Rock, Paper, Scissors" game.

## 🎯 Project Goal
To understand the Python pseudorandom generator (the `random` module) and master array indexes, offsets, and data collection structures.

## ✨ Project Contents

### 1. 🪨 Rock, Paper, Scissors (`RockPaperScissors.py`)
- Play the classic hand game against the computer.
- Features detailed multi-line ASCII graphics showing hand shapes.
- Contains comprehensive comparison logic to decide win, loss, or draw scenarios.

### 2. 🪙 Coin Tosser (`HeadsAndTails.py`)
- A quick random simulation returning either "Heads" or "Tails".

### 3. 💳 Banker Roulette (`WhoWillPayTheBill.py`)
- A utility that randomly selects one name from a list of friends to foot the bill at a restaurant.

## 🎓 Key Learnings
- Working with the `random` module and generating random integers using `random.randint()`.
- Declaring, accessing, and editing items in Python lists.
- Avoiding `IndexError` bugs by checking array boundaries dynamically with `len()`.
- Mapping array items directly to text variables (ASCII art styles) based on numeric index matching.

## 🚀 How to Run the Project
Make sure you have Python installed. Run your desired script in the terminal:
```bash
python RockPaperScissors.py
```
