# 💸 Day 3: Tip Calculator

A handy billing calculation utility designed to split a restaurant bill evenly among a group of people, incorporating a custom tip percentage.

## 🎯 Project Goal
To practice data type conversions (type casting), arithmetic operations, and float formatting with f-strings to produce a clean, user-friendly financial output.

## ✨ Features
- **Bill Splitting:** Divides the total bill evenly among any specified number of people.
- **Tip Calculation:** Supports customizable tip percentages (e.g., 10%, 12%, or 15%).
- **Precision Formatting:** Automatically rounds the individual share to exactly two decimal places.

## 📂 Project Structure
- `main.py` – the main program script containing all the calculator logic.

## 🎓 Key Learnings
- Converting string inputs into numeric types using `float()` and `int()`.
- Implementing standard arithmetic formulas in Python code.
- Utilizing f-strings to format float values to two decimal places (`{value:.2f}`).
- Using the `round()` function to handle monetary precision.

## 🚀 How to Run the Project
Make sure you have Python installed. Then run the following in your terminal:
```bash
python main.py
```
